

# EzEdit - All-in-One Tools

This contains everything you need to run the application locally.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key (optional for some tools)
3. Run the app:
   `npm run dev`
